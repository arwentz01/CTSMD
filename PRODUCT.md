# CTSMD Connect Commerce
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Theatre staff using laptops and tablets during busy performances; administrators managing setup; ticket purchasers using mobile and desktop browsers.

## Product Purpose
Integrated ticketing: scheduling, reserved seats and general admission, Box Office sales, orders, complimentary tickets, refunds, and admission.

## Capabilities and Constraints
Commerce redesign only. Preserve shared application navigation and service permission checks. Restricted storefront preview, synthetic transactions, no deployment, no live payment activation. Existing PHP, JavaScript and CSS stack; no schema migration required.

## Brand Commitments
CTSMD burgundy, ivory and gold. Compact, readable, consistent interfaces with accessible keyboard and touch operation.

## Product Principles
Separate setup from daily operations. Show real operational data. Reduce repeated controls. Preserve working workflows and payment safeguards.
